Dune Engine - Proyecto Universitario

Visualizador de geometría en OpenGL 3.3 con carga de modelos mediante Assimp, texturas con DevIL y cámara tipo Unity/FPS.

Instalar Más Información

Descripción del Proyecto

Soporta drag & drop de modelos y texturas, selección por raycast y transformaciones simples sobre el objeto seleccionado.

Cómo usar el Motor

Abrir el ejecutable

  • Se crea una ventana OpenGL (800×600) con depth test activado.
  • Se inicializan SDL3, DevIL y Assimp.
  • Se muestran logs de versión y GPU en consola.

Cargar modelos y texturas

  • Al iniciar se carga automáticamente la Baker House con su textura (Baker_house.png).
  • Se puede arrastrar y soltar modelos (.fbx, .obj, .dae, .gltf, .glb, .3ds, .ply, .blend) y texturas (.png, .jpg, .tga, .bmp, .psd, .gif, .hdr, .pic).
  • Los modelos se instancian frente a la cámara (~2.5 unidades).
  • Las texturas se aplican al objeto bajo el cursor o al seleccionado.

Selección

Click izquierdo para seleccionar un objeto. Se usa raycast con prueba AABB.

Render

Los modelos se renderizan con su shader asociado y pueden usar materiales originales o textura de override.

Controles

Cámara

W/A/S/D (botón derecho pulsado), SHIFT para velocidad, ALT + botón derecho para orbitar, rueda del ratón para zoom, F para centrar, ESC para salir.

Selección y Transformación

Click izquierdo para seleccionar, flechas para escalar/rotar, W/A/S/D y Q/E para mover.

Visualización

1: wireframe, 2: sólido

Funcionalidades Principales

  • Carga de modelos mediante Assimp.
  • Carga de texturas mediante DevIL.
  • Drag & Drop de modelos y texturas.
  • Selección por raycast con colisión AABB.
  • Cámara FPS libre, órbita y zoom.
  • Transformaciones básicas de objetos.
  • Shader system con carga desde archivo.
  • UI con ImGui (DockSpace, jerarquía, inspector, consola, panel GPU/escena, toolbar, menú superior).
  • Logs de GPU, versión OpenGL y errores.

Funcionalidades Extra

  • Modelos con materiales o con textura única.
  • Colocación automática de modelos frente a la cámara.

Dependencias Principales

  • SDL3 — Ventana e input
  • GLAD — Carga de funciones OpenGL
  • GLM — Matemáticas
  • Assimp — Carga de modelos
  • DevIL — Carga de imágenes
